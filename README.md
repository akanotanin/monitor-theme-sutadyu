# sutadyu

把 Monitor 的节点数据做成一座可以散步的体素小镇：**每台服务器是一只小鸡**。纯静态主题，无构建步骤，放进 hub 的主题目录即可。

![预览](preview.png?v=1)

## 预览

- `W A S D` / 方向键走动，`Shift` 小跑
- 镜头贴着地图边缘时，画面上看到的是继续延伸的田野：镇边往外有一圈泥土裙边、两级矮台地和一圈高矮不一的树篱，把直线边界打散；这些都是背景，走不过去
- **手机 / 平板**：左下虚拟摇杆走位，右下动作键等同 `E`（靠近小鸡/村民/告示牌/作物时才点亮，文字跟着变「详情 / 对话 / 公告 / 采摘」）；轻点小鸡也能直接开详情
- 宽屏下每只小鸡头顶**常驻信息卡**：状态、延迟、CPU / 内存 / 磁盘、流量（已用/总量，快满变黄/红）、实时带宽 ↓↑；窄屏自动收成「走近才展开」，**其余的鸡各留一颗状态点**（看得出图上还有别的机器、也不占地方）
- 顶栏「卡片」按钮：一键收起 / 展开所有小鸡头顶的卡片（含状态点；本机记忆，刷新不丢）
- 服务器多的时候自动「防糊」：同屏只留最近且互不叠放的一批完整卡（约 8~14 张，按屏宽），其余小鸡头顶缩成状态点，走近自然轮到它；小鸡落脚点按数量自动铺满全图，不会扎堆（40 台以内点位间距保证 ≥ 一张卡宽 6.0，更多时按地图容量逐级放宽）
- 走近或悬停那一只：卡片展开完整版（多出行/列 + 今日流量 + 公开备注）
- `E` 打开这只小鸡的详情卡；**点它头顶的卡片也能开**（卡片比小鸡本体大 11 倍，是更好点的目标）；详情页开着时镜头**钉在那台机器上**（不会被玩家位置拉回去），关掉后平滑回到玩家
- `Tab` 打开**探针列表**悬浮层：点卡片看九格信息 + 资源 / 延迟折线图，镜头同时带到那台机器（每次打开会顺手刷一轮三网延迟，30 秒内不重复）
- 窄屏（手机）上，卡片被屏幕边缘切掉时会自动收成状态点，不会露出半张卡
- **一天里的光**：按访客本地时间做晨昏渐变——太阳方位随时间从东偏到西、色调从清晨的暖黄走到黄昏的橘红、夜里转成冷蓝，路灯到点才亮（白天熄灭）；也可以固定成白天 / 黄昏 / 夜里三档
- **五栋房子都有店招**（麦香面包 / 蓝顶小馆 / 青瓦茶寮 / 橙顶果蔬 / 紫顶工坊），挂在门楣上方、不受光照影响，夜里也读得清
- **烟火气**：烟囱往上冒烟，夜里草地与树旁有萤火虫（白天整层收掉，不占绘制）；`?fx=0` 可关掉
- **菜园按节点在线时长生长**：走近成熟作物按 `E` / 点动作键采摘，摘完立刻冒嫩芽、慢慢长回去；长回来的快慢取决于它归属的那台机器在线多久——**连轴转 30 天以上的地块 40 秒一轮，刚开机的要 150 秒**，把自己的 uptime 变成看得见的种地反馈
- **手机有一张小地图**（右上角）：竖屏只能看到全图的约两成，别的机器在哪个方向全靠它；点地图任意位置就能直接走过去。桌面档不显示
- **探针列表**：`Tab` 打开悬浮层，卡片一行三列、每台机器带国旗（本地包内自带 250 面，ISO 3166-1 两字母代码；`uk`/`en` 这类常见误填会自动归到 `gb`，没有填或不在表内则显示小地球而非破图）、系统与规格、CPU / 内存 / 磁盘三条横条、实时网速与今日流量、三网延迟丢包、公开备注
- **详情页**：九格信息（系统 / 架构 / 负载 → CPU / 内存·交换分区 / 硬盘 → TCP·UDP / 今日流量 / 在线时间，无框留白排布）、资源与网络延迟两个页签、五档时间范围、六张走势图两列三排
- **按 group 分街**：机器在 hub 里挂了 group 时，同一组会聚在同一条街上（组内沿街铺开、不同组分带），四十台以上一眼能看出「这几台是一伙的」
- **河水流得有多急，看全站实时总带宽**：闲时几乎不动，跑满时波光会明显加快（0.7~2.4 倍之间平滑过渡，不会一跳一跳）；入夜后水面会跟着一起暗下来、只在河心留一点月光，不会像一条自发光灯带突兀地亮着
- **桥下有一块水影**：木桥压在水面上的地方会暗下去一档（边缘是渐变的），桥不再是"漂"在河上；这层遮蔽按桥的实际位置直接算，不额外消耗阴影贴图
- **明信片模式**：按 `P`（或手机上点一下画面）收起所有界面与卡片，只留小镇本身，用来截图或挂在大屏上；再按一次回来
- **闲置巡游**：30 秒没操作，镜头会自己慢慢绕镇子走一圈（约两分钟一圈），一按键就平滑回到你身上；系统开了「减少动态效果」时完全不启动
- **小镇的声音**（默认关，点左下 `♪` 打开）：白天的鸟叫、夜里的虫鸣、采摘时的鸡叫、机器掉线/恢复的轻铃，全部用 WebAudio 现场合成，不下载任何音频文件。关掉时把音频上下文挂起，不是静音——真的不占 CPU
- 触屏直接点小鸡就能开详情（不必先悬停）；右键 / 中键不会误开
- 站点关闭公开页时，访客看到的是「本站未对访客开放」，而不是「未发现服务器」
- `Esc` 关闭面板；面板开着时 `E` 与空格都不会穿透到小镇（空格仍能按下面板里聚焦的按钮）
- **载入动画**：首屏不是空幕布——奶油色画面里一颗像素胶囊，小鸡一趟趟把木料搬过去，房子按真实加载进度一层层砌起来（放线 → 地基 → 三段墙 → 门 → 窗 → 两段屋顶 → 烟囱），树跟着长高、野花跟着冒头；进度条做成工地上的木牌，百分比刻在它下面的小木牌上。100% 时开窗点灯、撒花、小鸡原地蹦，幕布才淡出。**进度是真实的**：boot 取配置 / 站点信息 → 主模块模块图 → 首帧渲染，每个阶段才往上走一格，等得久时最多自动蹭到 88%，绝不提前宣布完成。点小鸡会跳一下（`prefers-reduced-motion` 下不跳）。

## 源码与构建

仓库里放的是手写源码，`dist/` 不入库（由构建生成）：

```text
src/                     源码：原生 ES 模块 + importmap，无打包器
├── index.html           页面与全部样式
├── boot.js              引导：先读 /api/me 与主题设置，再动态导入主模块
├── *.js                 小镇 / 小鸡 / 卡片 / 列表 / 详情 / 图表，每个模块都可直接读
└── vendor/three.module.js   three.js r169（MIT，全文见 THIRD-PARTY-NOTICES.md）
tools/build.mjs          src/ → dist/，并按 theme.json 的 version 给相对模块路径注入 ?v=
tools/pack.sh            构建 + 打成可复现的 theme.tar.gz
```

```bash
npm run build   # = node tools/build.mjs，产出 dist/
npm run pack    # 构建并打包 theme.tar.gz + theme.tar.gz.sha256
```

版本号只在 `theme.json` 的 `version` 写一次：构建时同步 `<meta name="theme-version">`、入口脚本与 importmap 的 `?v=`，所以发布包的哈希可以复现（条目顺序固定、mtime 与属主归零）。

## 主题设置

后台「主题 → sutadyu」里可调：

| 设置项 | 默认 | 说明 |
| --- | --- | --- |
| 镜头远近 | 标准 | 近景 / 标准 / 远景三档，正交俯视镜头的高度 |
| 小鸡名牌 | 智能（宽屏常驻 · 窄屏靠近） | 另有「一直常驻卡片 / 靠近才展开 / 只显示状态点」；`?labelMode=auto\|always\|near\|dot` 可即时预览 |
| 一天里的光 | 跟随访客本地时间 | 另有「固定白天 / 固定黄昏 / 固定夜里」；`?daylight=auto\|day\|dusk\|night` 可即时预览 |
| 村民与作物互动 | 开 | 关掉后镇子里只剩探针小鸡 |
| 实时阴影 | 开 | 关掉可显著提升弱显卡上的帧率 |
| 低画质启动 | 关 | 直接按低分辨率与无阴影启动，适合核显 / 手机 |

## 安装与许可

1. 从 [Releases](https://github.com/akanotanin/monitor-theme-sutadyu/releases) 下载最新 `theme.tar.gz`；
2. 面板 → 主题 → 安装主题，上传即可；之后可在面板里「从 GitHub 更新」。

> 发布资产名固定为 `theme.tar.gz` / `theme.tar.gz.sha256`：面板的「从 GitHub 更新」只认这个名字，改名会让一键更新直接失败（带版本号的包只作手工归档）。

包结构：`theme.json` + `preview.png` + `dist/`（站点根，hub 直接托管）+ `LICENSE` + `README.md` + `THIRD-PARTY-NOTICES.md`。

主题同源读取 hub 的公开接口（`/api/nodes`、`/api/ws`、`/api/me` 与主题配置），不落盘、不显示主机名与 IP。
