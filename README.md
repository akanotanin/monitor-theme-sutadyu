# sutadyu

把 Monitor 的节点数据做成一座可以散步的体素小镇：**每台服务器是一只小鸡**。纯静态主题，无构建步骤，放进 hub 的主题目录即可。

![预览](preview.png?v=1)

## 预览

- `W A S D` / 方向键走动，`Shift` 小跑
- 宽屏下每只小鸡头顶**常驻信息卡**：状态、延迟、CPU / 内存 / 磁盘、流量（已用/总量，快满变黄/红）、实时带宽 ↓↑；窄屏自动收成「走近才展开」
- 顶栏「卡片」按钮：一键收起 / 展开所有小鸡头顶的卡片（含状态点；本机记忆，刷新不丢）
- 服务器多的时候自动「防糊」：同屏只留最近且互不叠放的一批完整卡（约 8~14 张，按屏宽），其余小鸡头顶缩成状态点，走近自然轮到它；小鸡落脚点按数量自动铺满全图，不会扎堆（40 台以内点位间距保证 ≥ 一张卡宽 6.0，更多时按地图容量逐级放宽）
- 走近或悬停那一只：卡片展开完整版（多出行/列 + 今日流量 + 公开备注）
- `E` 打开这只小鸡的详情卡；详情页开着时镜头**钉在那台机器上**（不会被玩家位置拉回去），关掉后平滑回到玩家
- `Tab` 打开**探针列表**悬浮层：点卡片看九格信息 + 资源 / 延迟折线图，镜头同时带到那台机器（每次打开会顺手刷一轮三网延迟，30 秒内不重复）
- 窄屏（手机）上，卡片被屏幕边缘切掉时会自动收成状态点，不会露出半张卡
- 触屏直接点小鸡就能开详情（不必先悬停）；右键 / 中键不会误开
- 站点关闭公开页时，访客看到的是「本站未对访客开放」，而不是「未发现服务器」
- `Esc` 关闭面板；面板开着时 `E` 与空格都不会穿透到小镇（空格仍能按下面板里聚焦的按钮）

## 主题设置

后台「主题 → sutadyu」里可调：

| 设置项 | 默认 | 说明 |
| --- | --- | --- |
| 镜头远近 | 标准 | 近景 / 标准 / 远景三档，正交俯视镜头的高度 |
| 小鸡名牌 | 智能（宽屏常驻 · 窄屏靠近） | 另有「一直常驻卡片 / 靠近才展开 / 只显示状态点」；`?labelMode=auto\|always\|near\|dot` 可即时预览 |
| 村民与作物互动 | 开 | 关掉后镇子里只剩探针小鸡 |
| 实时阴影 | 开 | 关掉可显著提升弱显卡上的帧率 |
| 低画质启动 | 关 | 直接按低分辨率与无阴影启动，适合核显 / 手机 |

## 安装与许可

1. 从 [Releases](https://github.com/akanotanin/monitor-theme-sutadyu/releases) 下载最新 `theme.tar.gz`；
2. 面板 → 主题 → 安装主题，上传即可；之后可在面板里「从 GitHub 更新」。

> 发布资产名固定为 `theme.tar.gz` / `theme.tar.gz.sha256`：面板的「从 GitHub 更新」只认这个名字，改名会让一键更新直接失败（带版本号的包只作手工归档）。

包结构：`theme.json` + `preview.png` + `dist/`（站点根，hub 直接托管）+ `LICENSE` + `README.md` + `THIRD-PARTY-NOTICES.md`。

主题同源读取 hub 的公开接口（`/api/nodes`、`/api/ws`、`/api/me` 与主题配置），不落盘、不显示主机名与 IP。
